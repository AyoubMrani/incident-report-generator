### Description

A step-by-step visual guide (screenshots included) for extracting Line IDs from IMS for a specific list of Home IDs and using them to run a rollback via a Python script (menu.py).

### Summary of steps

Résumé / Summary of stepsStart with a list of Home IDs (e.g. ABY009675937001, ABY009698169001, ...).Format them  and copy them into an IMS SQL query that joins SITE, SITETYPE, and CIRCUITS to pull HOMEID, LINEID, LINE_STATUS, PROVISION_STATUS, and LINE_ORDERTYPE, filtered by HOME.NAME IN (...). SELECT

    HOME.NAME                                                                    AS HOMEID,

    C.CIRCUITNAME                                                                AS LINEID,

    C.STATUS                                                                     AS LINE_STATUS,

    (SELECT value FROM extrafieldvalues

      WHERE extrafieldid = 2397 AND objectid = C.CIRCUITID)                     AS PROVISION_STATUS,

    (SELECT value FROM extrafieldvalues

      WHERE extrafieldid = 2394 AND objectid = C.CIRCUITID)                     AS LINE_ORDERTYPE

FROM SITE HOME

    INNER JOIN SITETYPE STY ON STY.ID     = HOME.SITETYPEID

                            AND STY.NAME  LIKE 'CUSTOMER%'

    LEFT  JOIN CIRCUITS C   ON (C.SITE_A_ID = HOME.ID OR C.SITE_B_ID = HOME.ID)

                            AND C.SERVICEPARTS = 'SERVICE'

                            AND C.STATUS      != 'OOS'

WHERE UPPER(HOME.NAME) IN (

    -- Insert your target HOME IDs below. Example:

    -- 'ABY009675937001', 'ABY009698169001', 'ABY009810863001'

)

ORDER BY HOME.NAME;
Run the query and export results to Excel.Copy the LINEID column values from the exported Excel file.Paste them into ListlineID.txt.Open a terminal, cd into IMS Scripts_v1.0, run python menu.py.Choose option 7, then run the rollback by entering ListlineID.txt.
